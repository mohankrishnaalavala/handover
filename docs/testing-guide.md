## Prerequisites

| Requirement | Notes |
|-------------|-------|
| Python 3.11+ | `python3.11 --version` |
| `ANTHROPIC_API_KEY` | Required **only** for LLM mode (`--no-llm` bypasses it) |
| `watchdog>=4.0` | Required **only** for `handover watch` — install via `pip install handover[watch]` |
| `curl` | For HTTP bridge tests |


## Troubleshooting

### "No Claude Code sessions found"

The project hash formula replaces both `/` and `_` with `-`.
Verify with:

```bash
python3 -c "
from handover.parsers.claude_code import ClaudeCodeSessionParser
from pathlib import Path
print(ClaudeCodeSessionParser.project_hash(Path('/your/project/path')))
"
ls ~/.claude/projects/ | grep <expected-hash>
```

If the computed hash doesn't match, the session files are stored under a different directory
(e.g. a worktree). Use `--session` to point directly at the `.jsonl` file.

### "Could not resolve authentication method"

`ANTHROPIC_API_KEY` is not set. Either:
- `export ANTHROPIC_API_KEY=sk-ant-...` before running, or
- add `--no-llm` to use heuristic extraction

### "Port 7437 is already in use"

```bash
lsof -ti:7437 | xargs kill -9
```

Then restart `handover serve`.

### "watchdog is not installed"

```bash
pip install "handover[watch]"
```

### `handover serve --daemon` — process doesn't start

Check the log file:
```bash
cat ~/.handover/server.log
```

PID file location: `~/.handover/server.pid`

## Testing the Browser Extension Manually

1. Build: `bash scripts/build-extension.sh` → creates `dist/handover-extension.zip`
2. Install in Chrome: go to `chrome://extensions/` → enable Developer Mode → Load unpacked → select `extension/`
3. Start the bridge: `handover serve --port 7437 --output ~/your-project/`
4. Open `https://claude.ai` with an active conversation
5. Click the handover extension icon → set output directory → click "Send to Claude Code"
6. Check `~/your-project/CLAUDE.md` was created

See `docs/browser-extension.md` for full install + troubleshooting guide.
