# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

To report a vulnerability privately, use one of the following options:

1. **GitHub Private Advisory (preferred):** Open a [private security advisory](https://github.com/mohankrishnaalavala/handover/security/advisories/new) directly on the repository.
2. **Email:** Contact the maintainer privately at the email address listed on the [GitHub profile](https://github.com/mohankrishnaalavala).

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Any suggested mitigations if known

You can expect an acknowledgement within **48 hours** and a resolution timeline within **7 days** for critical issues.
